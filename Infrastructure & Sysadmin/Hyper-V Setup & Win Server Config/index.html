Hyper-V Setup & Windows Server Config

Enabling the Hyper-V role, standing up a virtual switch bound to the physical NIC, and building out a Windows Server 2022 Evaluation VM from the New Virtual Machine Wizard through first login.

1

Enabling Hyper-V via PowerShell

Turning on the Hyper-V role from an elevated PowerShell session instead of the GUI feature toggle.
1

Kick off the feature install

From an elevated PowerShell session: Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All -NoRestart. The -NoRestart flag lets the reboot happen on my terms rather than immediately.

2

Feature install running

Windows begins staging the Hyper-V role components in the background.

3

Still installing

The progress bar holds here for a bit while the full Hyper-V-All bundle (platform, services, management tools) gets pulled in.

4

Restart to finish

Output confirms RestartNeeded : True. Rebooting immediately with shutdown /r /t 00 to complete the install rather than waiting on a scheduled restart.

2

Hyper-V Manager & Virtual Switch Setup

Standing up an External virtual switch so future VMs can reach the physical network.
1

Launch Hyper-V Manager

Opening the Hyper-V Manager console after the reboot completes.

2

Clean slate

Connected to SRV-HYPERV-01 with no virtual machines yet — the host is ready to be configured.

3

Open Virtual Switch Manager

Right-clicking the host and selecting Virtual Switch Manager... to create the network layer VMs will connect to.

4

Create an External switch

Choosing External so the switch binds to the physical NIC, giving VMs direct access to the LAN rather than being isolated behind NAT.

5

Bind to the physical adapter

Named it vSwitch0 and pointed it at the Intel(R) Ethernet Connection (17) I219-LM, with Allow management operating system to share this network adapter checked so the host keeps connectivity too.

6

Confirm the network change

Hyper-V warns that applying the switch can briefly disrupt network connectivity while it rebinds the adapter — expected, so clicking through.

7

Switch is live

vSwitch0 now shows bound to the Intel Ethernet Connection, ready to be assigned to virtual machines.

8

Ready to build

Back at the main Hyper-V Manager view — networking is in place, so the next step is creating the actual VM.

3

Creating the Windows Server 2022 VM

Walking through the New Virtual Machine Wizard to define the hardware shell before installing an OS.
1

Start the New VM Wizard

Right-clicking the host → New → Virtual Machine... to launch the wizard.

2

Before You Begin

Skipping the defaults and going through the custom configuration path instead of clicking Finish early.

3

Name and location

Named it Windows Server 2022 Eval and stored it on the D:\ volume rather than the default system drive.

4

Generation 2

Choosing Generation 2 for UEFI firmware and support for newer virtualization features, since this can't be changed later.

5

Assign memory

8096 MB startup memory with Use Dynamic Memory enabled so the VM can flex based on actual demand.

6

Attach to vSwitch0

Connecting the VM's network adapter to the vSwitch0 external switch built in the previous section.

7

Create the virtual disk

A new 127 GB dynamically expanding VHDX, stored alongside the VM on D:\.

8

Point to install media

Choosing Install an operating system from a bootable image file and browsing to the downloaded ISO.

9

ISO selected

The Windows Server 2022 Evaluation ISO (SERVER_EVAL_x64FRE...) is set as the boot image.

10

Review and finish

Summary confirms Generation 2, 8096 MB, vSwitch0, the 127 GB VHDX, and the ISO source before clicking Finish.

11

VM shell created

Windows Server 2022 Eval now sits alongside the existing Ubuntu Server VM in the inventory, both powered off.

12

Connect to the VM

Right-clicking the new VM to bring up Connect... and the rest of the VM action menu.

13

Ready to power on

The VM Connection console confirms it's currently off — time to hit Start and boot from the ISO.

4

Installing Windows Server 2022

From first boot off the ISO through the OS install to the initial desktop and Server Manager.
1

Boot from the ISO

Catching the "Press any key to boot from CD or DVD" prompt to kick off setup from the attached image.

2

Locale settings

Confirming language, time/currency format, and keyboard layout before proceeding.

3

Install now

Kicking off the actual OS installation from the setup splash screen.

4

Setup starting

Brief loading screen while setup initializes.

5

Choose the edition

Selected Windows Server 2022 Standard Evaluation (Desktop Experience) for the full GUI environment.

6

Accept license terms

Reviewing and accepting the Microsoft Software License Terms.

7

Custom install

Going with Custom: Install Microsoft Server Operating System only since this is a clean VM with no prior OS.

8

Select the target drive

Installing to the full 127 GB of unallocated space on the virtual disk.

9

Copying files

Setup copies OS files and begins getting them ready for installation.

10

Installing features

Files copied and features installed; updates and final setup steps are next.

11

Restart to continue

Setup requires a restart to finish applying the installation.

12

First boot

The VM comes back up through the Hyper-V boot splash.

13

Getting ready

Windows finalizes the install and prepares the environment for first-time setup.

14

Set the Administrator password

First-run out-of-box experience — setting the password for the built-in local Administrator account.

15

Lock screen

Setup completes and drops to the lock screen.

16

First login

Signing in with the Administrator account for the first time.

17

First desktop

Clean desktop, ready for role and feature configuration.

18

Server Manager Dashboard

Server Manager launches automatically, showing the local server and the default File and Storage Services role — the starting point for building out AD, DNS, and DHCP in the next write-up.

19

Snapshot the clean state

Back in Hyper-V Manager, an automatic checkpoint captured the freshly installed state — a safe rollback point before role configuration begins.
